    Introduction

    cmuggui is a library for building GUIs in CMU Graphics.

    Install

    To install, run pip install cmuggui in the command line.

    Classes

    Menu

    Menu(*args, fill=Colors.gray, border=Colors.darkerGray, debug: bool = False, **kwargs):

    The Menu class subclasses the Rect class from CMU Graphics. This means that normal Rect arguments like left and top are still passed.

    Args

    • fill: the color of the background.
    • border: the color of the border.
    • debug: when True, lines are drawn that show alignment and where the border is. Useful if fill and border are invisible. This also automatically calls the getData() method.

    Methods

    • getData(): returns a Dict containing data about the object.
