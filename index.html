    Introduction

    cmuggui is a library for building GUIs in CMU Graphics.

    Install

    To install, run pip install cmuggui in the command line.

    Classes

    Menu

    Menu(*args, fill=Colors.gray, border=Colors.darkerGray, debug: bool = False, **kwargs):

    The Menu class subclasses the Rect class from CMU Graphics. This means that normal Rect arguments like left and top are still passed.

    Keyword Arguments

    • fill: the color of the background.
    • border: the color of the border.
    • debug: when True, lines are drawn that show alignment and where the border is. Useful if fill and border are invisible. This also automatically calls the getData() method.

    Methods

    • getData(): returns a Dict containing data about the object.

    Menu.Button

    Menu.Button(parent, onclick,
horizontalAlign: int|float, verticalAlign: int|float,
width: int|float, height: int|float, fill = Colors.darkgray, borderFill = Colors.darkerGray, borderWidth: int|float = 2,
textValue: str = "", textFill = "black", textFont: str = "arial", textSize: int|float = 12,
textIsBold: bool = False, textIsItalic: bool = False, textIsVisible: bool = True,
debug: bool = False)

    This class does not subclass a CMU Graphics class, meaning instances of it cannot be added into a CMU Graphics Group.

    Arguments

    • parent: a Menu object.
    • onclick: the name of a Python function.
    • horizontalAlign: the left of the button in relation to the parents centerX property.
    • verticalAlign: the top of the button in relation to the parents top property.
    • width: the width of the button.
    • height: the height of the button.

    Keyword Arguments

    • fill: the color of the buttons background.
    • borderFill: the color of the buttons border.
    • borderWidth: the width of the buttons border.
    • textValue: the text displayed on the button.
    • textFill: the color of the text.
    • textFont: the font of the text.
    • textSize: the size of the text.
    • textIsBold: whether or not the text should be bold.
    • textIsItalic: whether or not the text should be italic.
    • textIsVisible: whether or not the text should be visible.
    • debug: when True, lines are drawn that show alignment and where the border is. Useful if fill and border are invisible. This also automatically calls the getData() method.

    Methods

    • getData(): returns a Dict containing data about the object.

    Event Listeners

    addEventListener(x, y, event: str = "mouseDown")

    Event listeners are defined inside of the onMousePress function from CMU Graphics. When an event listener is defined, they must take x and y. Do not pass anything for the event argument. It will cause an error. An example is shown below.


    def onMousePress(x, y):
  buttonObject.addEventListener(x, y)

    Functions

    This class defines utiity functions.

    Functions.QUIT()

    Quits the program using sys.exit(0).

    Functions.QQUIT()

    Quits the program by raising a KeyboardInterrupt.

    Functions.toggleVisibility(object)

    Toggles the visibilty of the object that is passed.

    Functions.translate(object, translateX, translateY)

    Translates the centerX and centerY of the object that is passed.

    Functions.rotate(object, degrees, origin="object_Center", originX=None, originY=None)

    Rotates the object that is passed based on an origin.

    Possible Origins
    • "origin_Center": the center of the object.
    • "origin_TopLeft": the top left coordinate of the object.
    • "origin_TopRight": the top right coordinate of the object.
    • "origin_BottomLeft": the bottom left coordinate of the object.
    • "origin_BottomRight": the bottom right coordinate of the object.
    • "origin_Custom": a custom coordinate to rotate the object around.

    Colors

    • darkerGray: rgb(100,100,100)
